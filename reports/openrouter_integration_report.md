## 2. API Error Handling Matrix

The pipeline incorporates robust, non-blocking HTTP error handling:

- **HTTP 401 (Unauthorized)**: Triggers an immediate safe stop with `API_ERROR: Invalid OpenRouter API Key`. Historical data is preserved.
- **HTTP 402 (Payment Required / Insufficient Credits)**: Triggers an immediate safe stop with `API_ERROR: Insufficient OpenRouter Credits`.
- **HTTP 429 (Rate Limit / Quota Exhausted)**: Applies exponential backoff with server delay + 2s padding. Stops cleanly after 5 consecutive failures without overwriting.
- **HTTP 5xx / Network Timeouts**: Retries up to 4 times with progressive backoff.
- **Token Limits**: Explicitly sets `max_tokens: 1000` to prevent OpenRouter from reserving default model max tokens (e.g. 65,536) against credit balances.
